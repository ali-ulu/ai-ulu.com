# ai-ulu.com

Web sites for businesses and individuals. Fast, secure, conversion-focused sites
deployed on Cloudflare.

## Stack

- Static site generated by a small dependency-free Node build (`scripts/build.mjs`)
- Home page: scroll-scrubbed 3D film (`src/site/client/home/`, OGL, bundled by esbuild into `dist/js/`; ledger in `MOTION.md`)
- `/sablonlar/`: React + Tailwind + shadcn gallery, npm workspace `apps/sablonlar` (Vite), built before the site
- Fonts, scripts and images are all self-hosted; the CSP in `_headers` allows `'self'` only and `npm run check` fails on any third-party asset URL
- Cloudflare Worker for the contact form API (`src/worker.js`)
- Cloudflare D1 for lead storage, Cloudflare Email for notifications
- Cloudflare Workers static assets for hosting

## Commands

```bash
npm install        # install dev deps (wrangler) and the gallery workspace
npm run build      # build apps/sablonlar, then generate dist/
npm run check      # verify build output
npm test           # run unit tests
npm run dev        # build + local preview (wrangler dev)
npm run deploy     # build + deploy to Cloudflare
npm run ping       # submit sitemap URLs to IndexNow (Bing, Yandex)
```

## Search engines and AI crawlers

- `robots.txt` allows every crawler and lists the sitemap; AI crawlers (GPTBot, PerplexityBot,
  ClaudeBot, Google-Extended) are named so the site stays eligible for AI answers. `llms.txt` is
  published for the same reason.
- Deploying from `main` runs `npm run ping` after the Cloudflare deploy. It posts the sitemap
  URLs to [IndexNow](https://www.indexnow.org/) (Bing, Yandex and partners) using the key in
  `src/site/config.mjs`. The build serves the matching key file at `/<key>.txt`.
- Google has retired its sitemap ping endpoint: submit `https://ai-ulu.com/sitemap.xml` once in
  [Google Search Console](https://search.google.com/search-console) and in
  [Bing Webmaster Tools](https://www.bing.com/webmasters). Use `npm run ping -- --dry-run` to see
  what would be sent.

## Structure

```
src/site/          site source (content, components, pages, assets)
src/site/client/   browser modules bundled at build (home film, funnel)
apps/sablonlar/    /sablonlar/ gallery (React, components in src/components/ui)
src/worker.js      contact form API
scripts/build.mjs  static site generator
test/              unit tests
schema.sql         D1 schema (apply once per database)
```

## First deploy

1. Set repository secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
2. Apply the D1 schema once:
   `npx wrangler d1 execute ai-ulu-leads --remote --file=schema.sql`
3. Push to `main` — CI builds, tests, and deploys.

`wrangler deploy` also registers the daily cron in `wrangler.jsonc`; the
`scheduled` handler in `src/worker.js` prunes stale rate-limit rows and leads
older than the retention window. Verify the SPF/DKIM/DMARC records for
`ai-ulu.com` (see `SECURITY.md`) so `noreply@ai-ulu.com` cannot be spoofed.

`package-lock.json` is committed and CI installs with `npm ci`; do not delete
it.
