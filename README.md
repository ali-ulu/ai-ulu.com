# ai-ulu.com

Web sites for businesses and individuals. Fast, secure, conversion-focused sites
deployed on Cloudflare.

## Stack

- Static site generated by a small dependency-free Node build (`scripts/build.mjs`)
- Cloudflare Worker for the contact form API (`src/worker.js`)
- Cloudflare D1 for lead storage, Cloudflare Email for notifications
- Cloudflare Workers static assets for hosting

## Commands

```bash
npm install        # install dev deps (wrangler)
npm run build      # generate dist/
npm run check      # verify build output
npm test           # run unit tests
npm run dev        # build + local preview (wrangler dev)
npm run deploy     # build + deploy to Cloudflare
```

## Structure

```
src/site/          site source (content, components, pages, assets)
src/worker.js      contact form API
scripts/build.mjs  static site generator
test/              unit tests
schema.sql         D1 schema (apply once per database)
```

## First deploy

1. Set repository secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
2. Apply the D1 schema once:
   `npx wrangler d1 execute ai-ulu-leads --remote --file=schema.sql`
3. Push to `main` — CI builds, tests, and deploys.
