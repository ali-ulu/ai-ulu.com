# Task Standard

TASK-### contains:
- objective
- linked REQ/NFR/SPEC/ADR
- expected output
- dependencies
- allowed scope/files/modules
- forbidden scope
- constraints
- acceptance criteria
- required checks
- risk level
- rollback consideration
- context pack ID/version
- EXE ID
- status

A task must be understandable without giving permission to redesign unrelated parts.
