# Task Handoff Contract

Every completed/blocked task leaves:
- source BASE and context pack version
- inputs consumed
- outputs produced
- changed files/artifacts
- tests/checks and results
- decisions made within authority
- CHG/DEV/APR/REC IDs
- discovered constraints
- unresolved issues
- risks introduced/closed
- next tasks unblocked
- required revalidation

The next worker should not need chat history to reconstruct state.
