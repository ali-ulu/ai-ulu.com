# Deployment & Distribution Strategy

Deployment execution may be optional. Deployment architecture is part of planning.

Define:
- target: web/mobile/desktop/API/AI service
- hosting/environment/provider
- regions/data residency
- database/storage location
- CDN/edge needs
- domain/DNS/TLS
- secrets/configuration
- CI/CD release path
- observability
- backups
- rollback
- distribution: website/App Store/Play Store/installer/container/private enterprise

## Definition of Production
State the conditions under which the project is genuinely production-ready: health, migrations, secrets, backups, monitoring, error logging, security checks and rollback readiness.
