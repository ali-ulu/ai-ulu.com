# Engineering Constitution

1. Never convert an assumption into a fact without evidence or customer confirmation.
2. Never invent a requirement to make design easier.
3. Unknown, blocked and needs-research are valid states.
4. Prefer the simplest viable architecture for validated requirements.
5. No scope expansion without CHG-###.
6. Every requirement needs a source and acceptance criteria.
7. Every SPEC-### references one or more requirements.
8. ADRs state context, alternatives, decision, consequences and affected artifacts.
9. Every implementation task traces to requirements/specifications/decisions.
10. No dependency without purpose, license, maintenance and security review.
11. Security, privacy, reliability, observability and maintainability are design concerns.
12. Human approval is mandatory for protected decision classes.
13. Agents stop when a stop condition triggers.
14. Deviations are recorded before implementation continues.
15. Only an approved baseline represents project truth.
16. Research claims require provenance.
17. Process weight scales with complexity and risk.
18. A project may terminate with NO-GO.
19. Verification evaluates implementation against the agreed engineering contract.
20. One project's learning cannot become universal policy without review.
