# Project Profile & Process Selection

## Project type
WEB_SAAS, MOBILE, DESKTOP, API_SERVICE, DATA_PIPELINE, AI_LLM_APP, INTERNAL_TOOL, INTEGRATION, LIBRARY_SDK, INFRA_PLATFORM, OTHER.

## Complexity
- LEAN: small, low-risk, few actors/integrations
- STANDARD: normal commercial product
- EXTENDED: multiple domains/integrations or material operational risk
- CRITICAL: regulated, safety/security critical, high financial/reputational impact

## Method selection
- stable regulated requirements → stronger plan-driven baselines/approvals
- evolving product discovery → iterative/Kanban-style flow
- behavior-heavy domain → BDD emphasis
- critical logic → TDD emphasis
- AI-agent implementation → specification-driven tasks + execution contracts
- high deployment frequency → DevOps/continuous-delivery emphasis

Every artifact is REQUIRED, CONDITIONAL or NOT-REQUIRED. A small CRUD project must not receive critical-system ceremony.
