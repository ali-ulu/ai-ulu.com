# Review Receipt

May include:
- project and BASE-###
- scope reviewed
- implementation commit/release
- automated checks
- AI findings
- human findings
- severity distribution
- requirement/spec coverage
- unresolved concerns
- PASS / PASS-WITH-CHANGES / FAIL / BLOCKED
- reviewers/methods
- date
- limitations

A receipt is evidence of scoped verification, not a guarantee software can never fail.
