# Review Work Order

REV-### input:
- project / BASE-###
- review scope
- linked REQ/NFR/SPEC/ADR/TASK/EXE
- repository commit/diff
- review criteria
- risk level
- timebox if used
- expected output: PASS / FAIL / CONCERN
- finding format: severity, evidence, affected requirement/contract, recommendation

Human reviewers should not need to rediscover the whole project.
