# Baseline & Versioning

Canonical project truth is an approved BASE-###.

A baseline records exact versions/hashes of:
- needs/evidence snapshot
- requirements/NFRs
- specifications
- scope
- architecture/ADRs
- data model
- deployment strategy
- dependencies/lock state
- task graph/execution contracts
- repository commit when implementation has begun
- approvals

Changes do not rewrite history. Approved impact analysis produces a new baseline.
