# Commercial Service Model

## 1 — Blueprint / Project Preparation
Discovery, research, validation, requirements, specifications, architecture, data, deployment strategy, risks, task graph and execution plan.

## 2 — Build / Implementation
Implementation against an approved blueprint/baseline. Changes and deviations are controlled.

## 3 — Verify / Engineering Review
Automated + AI and optional human/hybrid review, ending in a scoped review receipt.

## + Launch / Deploy Add-on
Production deployment, distribution, monitoring, backups, rollback and launch handoff.

Bundles:
- Blueprint only
- Review only
- Blueprint + Review
- Blueprint + Build
- Full Cycle: Blueprint + Build + Verify
- Full Cycle + Launch

Deployment target is decided during Blueprint even when Launch is not purchased.
