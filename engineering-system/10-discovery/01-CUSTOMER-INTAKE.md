# Customer Intake

Capture only what the customer knows. Unknown is valid.

- Project / organization
- Problem to solve
- Intended users and actors
- Current workaround / existing solution
- Desired outcomes
- Must-have capabilities
- Nice-to-have ideas
- Explicit out-of-scope items
- Existing code/repository/infrastructure
- Expected scale and geography
- Data types and sensitivity
- Integrations
- Budget/time constraints if available
- Target platforms
- Deployment/distribution expectations
- Compliance/security constraints
- Known competitors/references
- Stakeholders/approvers
- Unknowns
